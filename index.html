Misión 1 · El alma del juego

Una leyenda real. Un robo que no lo es.

El juego parte de una de las leyendas más buscadas de Sudamérica. Cada robo, cada ciudad y cada personaje existe por una razón dentro de esa historia.

EL HOOK · LOGLINE Cuatro llaves, cuatro regiones y un equinoccio para salvar el tesoro más buscado del Ecuador.
LO QUE ES REAL

El oro de Rumiñahui

En 1533 los conquistadores ejecutaron a Atahualpa después de cobrar su rescate en oro y plata. Según la leyenda, otra parte del oro que aún iba en camino la escondió el general Rumiñahui en las montañas de los Llanganates. Décadas después, un español llamado Valverde, que según se cuenta se enriqueció con ese oro, dejó escrito un derrotero con el camino al tesoro. Nadie lo ha encontrado jamás.

LO QUE IMAGINAMOS

Los Guardianes del Inti

El derrotero estaba incompleto a propósito. El camino verdadero se grabó en un Disco Solar partido en cuatro llaves, como las cuatro regiones del Tawantinsuyu, y cada llave se escondió dentro de un objeto de una fiesta o tradición. Así, los pueblos protegieron el secreto durante 500 años solo con conservar su cultura.

EL CONFLICTO

¿Por qué roban?

El Rey Brumario, descendiente del autor del derrotero, sabe que existen cuatro llaves, pero no en qué objeto está cada una. Por eso su banda, la Bruma, roba entre humo y niebla las reliquias más importantes de cada región.

LA URGENCIA

¿Por qué hay prisa?

El disco solo revela el camino final bajo el sol del equinoccio en la Mitad del Mundo, cuando al mediodía casi no hay sombras. Si Brumario reúne las llaves antes, el tesoro será suyo.

La ruta del derrotero

Cada llave señala la siguiente ciudad

El jugador no elige el camino: lo descubre. Al pulsar JUGAR aparece el mapa del Ecuador con la Costa, la Sierra y la Amazonía; cada ciudad es un nivel con su aliado, y la llave recuperada en cada capítulo trae grabada la pista que abre el siguiente.

  1. Quito: el prólogo

    ● JUGABLE

    La Bruma roba la máscara solar del museo. Roco, el mecánico que restaura sus mecanismos, vio el robo. Alba le revela el secreto de los Guardianes y juntos persiguen a los ladrones por las calles de Quito.

    Pista: «busca a la reina que baila de negro».

  2. Latacunga y el páramo del Cotopaxi

    ● JUGABLE

    Desaparece un adorno del traje de la Mama Negra. Brin, el zorro del páramo, siguió a la Bruma por su territorio y guía al equipo.

    Pista: dentro del adorno aparece un símbolo cañari.

  3. Cuenca: Pumapungo

    ● JUGABLE

    Lino descifra los símbolos y descubre que el Disco Solar es un mapa y una máquina. Giro: Brumario les tiende una trampa, secuestra a Alba y se lleva las tres llaves, porque solo una guardiana puede leer el disco.

    Pista: «donde nace el sol, el río baja verde».

  4. Amazonía: Tena

    ● JUGABLE

    La Bruma saca reliquias del país por el río. Con Milo, el guardián del bosque, el equipo recupera la cuarta llave, la única que Brumario no tiene. Ahora él los necesita a ellos.

    Pista: el disco completo apunta a la Mitad del Mundo.

  5. Mitad del Mundo → Llanganates

    ● GRAN FINAL JUGABLE

    Bajo el sol del equinoccio aparece el camino verdadero. En la niebla de los Llanganates, Nuba deja pasar solo a quienes vienen a proteger el tesoro. El equipo rescata a Alba y deja el oro donde Rumiñahui lo escondió. Ahora todos son Guardianes del Inti.

EL VILLANO

Rey Brumario y la Bruma

«Rey Brumario» es el apodo de Augusto Valverde, el rey del mercado negro de antigüedades y descendiente del autor del derrotero. Su familia pasó generaciones buscando el oro y terminó arruinada y ridiculizada. Quiere demostrar que tenían razón, quedarse con el tesoro y vender las reliquias en el extranjero.

Su banda, la Bruma, roba siempre envuelta en humo y niebla artificial. Es lo contrario de Nuba: la Bruma esconde para robar, y Nuba esconde para proteger.

Misión legendaria · CI/CD

La fábrica automática

No subimos nada a mano. Cada push a main despierta a un robot de GitHub Actions que construye el juego y lo publica a la vez en GitHub Pages y en itch.io.

git push→ npm ci→ npm run build→ GitHub Pages+ npm run build:itch→ itch.io (Butler)

✔ JOB 1 · GitHub Pages (landing + juego)

# .github/workflows/deploy-pages.yml
on:
  push:
    branches: [main]
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: 22, cache: npm }
      - uses: actions/configure-pages@v5
      - run: npm ci
      - run: npm run build
      - uses: actions/upload-pages-artifact@v3
        with: { path: dist }
  deploy:
    needs: build
    environment: github-pages
    steps:
      - uses: actions/deploy-pages@v4

✔ JOB 2 · itch.io con Butler (CLI oficial)

# Secret   BUTLER_API_KEY (nunca en el código)
# Variable ITCH_GAME = usuario/juego
  itch:
    if: ${{ vars.ITCH_GAME != '' }}
    env:
      BUTLER_API_KEY: ${{ secrets.BUTLER_API_KEY }}
      ITCH_GAME: ${{ vars.ITCH_GAME }}
    steps:
      - run: npm ci
      - run: npm run build:itch
      - name: Install Butler
        run: curl -fsSL -o butler.zip \
          https://broth.itch.zone/butler/linux-amd64/LATEST/archive/default
          && unzip butler.zip -d ~/butler
      - name: Push to itch.io
        run: ~/butler/butler push dist-itch \
          "$ITCH_GAME:html5"

Usamos el CLI oficial de itch.io en lugar de una acción de terceros para que la API key solo la vea código de itch.io. Resultado: en unos 2 minutos cada cambio queda publicado en el mundo sin abrir la plataforma.
